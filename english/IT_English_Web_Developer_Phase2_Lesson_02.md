# Phase 2 — Lesson 2: Jira Tasks, Tickets & Requirements

**Thời lượng:** 90–120 phút

## 1. Core Vocabulary

`ticket`, `task`, `requirement`, `acceptance criteria`, `scope`, `priority`, `estimate`, `assignee`, `deadline`, `dependency`, `clarification`, `edge case`, `expected behavior`, `actual behavior`.

## 2. Essential Collocations

```text
create a ticket
assign a task
clarify a requirement
define the scope
estimate the task
set the priority
meet the deadline
add acceptance criteria
handle an edge case
provide more details
confirm the requirement
depend on another task
```

## 3. Useful Patterns

> Could you clarify this requirement?

> What should happen if the request fails?

> Are there any edge cases we need to handle?

> Does this task include the frontend changes?

> What is the expected behavior?

> The current behavior is different from the expected behavior.

> This task depends on the authentication service.

> I need more information before implementing this.

> Could you provide an example?

> Can we confirm the scope before I start?

## 4. Reading — A New Jira Ticket

> The product team created a ticket for a new password reset feature. The requirement says that users should be able to request a password reset link by providing their email address.
>
> Before starting the implementation, the developer reviews the acceptance criteria. The developer notices that the requirement does not explain what should happen when the email address does not exist.
>
> The developer asks the product owner to clarify this edge case. The product owner confirms that the API should return a generic response so that the system does not reveal whether an email address exists.
>
> After the requirement is clarified, the developer can estimate the task and start the implementation.

## 5. Translation

1. Could you clarify this requirement?
2. What should happen if the user does not exist?
3. Are there any edge cases?
4. Does this task include frontend changes?
5. This task depends on another service.
6. We need to confirm the scope before implementation.
7. The acceptance criteria are not clear.
8. Could you provide an example?

## 6. Reverse Translation

1. Bạn có thể làm rõ yêu cầu này không?
2. Điều gì sẽ xảy ra nếu request thất bại?
3. Có edge case nào chúng ta cần xử lý không?
4. Task này có bao gồm thay đổi frontend không?
5. Chúng ta cần xác nhận scope trước khi triển khai.

## 7. Practical Task

Viết 5 câu hỏi bằng English cho một Jira ticket có yêu cầu chưa rõ.

**80/20:** `Could you clarify...?` / `What should happen if...?` / `Does this include...?` / `Are there any...?` / `Could you provide...?`
