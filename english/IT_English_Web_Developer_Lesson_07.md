# 5. Reading — From Code to Production

> Before a new version of a web application is released, the code usually goes through several automated steps. The application is first built, and automated tests are executed to verify that the changes work as expected.
>
> If the tests pass, the application can be deployed to a staging environment. Developers and testers can then verify the application before it is released to production.
>
> The deployment process is often managed by a CI/CD pipeline. The pipeline may build a container image, run tests, deploy the application, and check the health of the service.
>
> If a production deployment causes a serious problem, the team may roll back to the previous version. After the issue is fixed, a new version can be deployed.
