# Phase 3 — Lesson 6: Code Review Conflict Simulation

**Thời lượng:** 120–150 phút

## Scenario

Bạn mở Pull Request.

Reviewer viết:

> I don't think we should introduce this abstraction. It makes the code more complex.

Bạn không hoàn toàn đồng ý.

---

## 1. Respond Politely

Viết câu trả lời bằng English.

Phải:

- acknowledge the concern
- explain your reasoning
- discuss trade-off
- remain professional

---

## 2. Reviewer Response

> The abstraction is only used by one component. Why don't we keep it simple?

Bạn trả lời 5–7 câu.

---

## 3. Alternative

Reviewer đề xuất:

> Let's use a simpler implementation now and refactor later if necessary.

Bạn cần:

- agree hoặc disagree
- giải thích lý do
- đề xuất compromise nếu cần

---

## 4. Practical Language

Sử dụng:

```text
I see your point.
That's a valid concern.
My reasoning is...
The reason I introduced this is...
I agree that...
However,...
One alternative would be...
I'm open to...
```

---

## 5. Final Decision

Team quyết định:

> Use the simpler implementation.

Viết response:

> I agree with the decision. I'll update the PR accordingly.

Sau đó viết thêm 3–5 câu giải thích.

---

## Success Criteria

Mục tiêu không phải thắng tranh luận.

Mục tiêu:

> **Explain → listen → negotiate → reach a technical decision.**
