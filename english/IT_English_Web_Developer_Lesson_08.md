# 3. Daily Standup Patterns

### Yesterday

> I finished the API implementation yesterday.

### Today

> Today, I am working on the database migration.

### Blocker

> I am currently blocked by an authentication issue.

### Asking for help

> Could you help me investigate this issue?

### Clarification

> Could you clarify this requirement?

### Progress

> The implementation is almost complete.

---

# 4. Requirement Patterns

> The system should allow users to reset their passwords.

> Users must provide a valid email address.

> The API should return a 404 status code when the resource cannot be found.

> The application needs to support multiple languages.

> The feature is required for the next release.

### Useful patterns

```text
The system should + V
Users must + V
The application needs to + V
The feature is required for + noun
```

# 5. Reading — A Developer's Daily Update

> Yesterday, I finished the implementation of the user authentication API. I also added tests for the login and password reset endpoints.
>
> Today, I am working on the database migration required for the new user profile feature. I also need to update the API documentation so that the frontend team can start integrating the new endpoints.
>
> I currently have one blocker. The authentication service is returning an unexpected error in the staging environment. I am investigating the issue and will ask the backend team for help if I cannot reproduce the problem locally.
>
> Before the end of the sprint, I need to finish the migration, resolve the authentication issue, and update the documentation.

# 10. Technical Documentation Pattern

Một technical document thường dùng các cấu trúc:

```text
This document describes...
This API is used to...
The endpoint accepts...
The request must contain...
The response contains...
If ..., the server returns...
The following example shows...
```

Ví dụ:

> This document describes how to authenticate with the API.

> The endpoint is used to retrieve user information.

> The request must contain a valid access token.

> If the token is invalid, the server returns a 401 status code.
