# Phase 2 — Lesson 1: Daily Standup & Progress Updates

**Role:** Web Developer  
**Thời lượng:** 90–120 phút  
**Mục tiêu:** Có thể báo cáo công việc ngắn gọn, nói về progress, blocker và kế hoạch tiếp theo.

## 1. Core Vocabulary

| English | Vietnamese | Common phrases |
|---|---|---|
| progress | tiến độ | make progress |
| update | cập nhật | give an update |
| task | công việc | work on a task |
| completed | đã hoàn thành | task is completed |
| ongoing | đang diễn ra | work is ongoing |
| blocker | trở ngại | have a blocker |
| blocked | bị chặn | be blocked by |
| investigate | điều tra/xem xét | investigate an issue |
| continue | tiếp tục | continue working on |
| complete | hoàn thành | complete a task |
| estimate | ước lượng | estimate the work |
| priority | ưu tiên | high priority |
| deadline | hạn chót | meet a deadline |
| pending | đang chờ | pending task |
| depend on | phụ thuộc vào | depend on another team |

## 2. Essential Patterns

> Yesterday, I worked on the authentication API.

> Today, I am working on the database migration.

> I have completed the implementation.

> I am currently working on the tests.

> I am blocked by an issue with the API.

> I am waiting for the frontend team.

> I expect to finish this task today.

> Once this is done, I will start working on the next task.

> I need more information before I can continue.

> There are no blockers at the moment.

## 3. Reading

> Yesterday, I finished the implementation of the user authentication API. I also added tests for the login endpoint and password reset flow.
>
> Today, I am working on the database migration for the new user profile feature. I am also reviewing the API documentation to make sure the frontend team has everything they need.
>
> I currently have one blocker. The authentication service is returning an unexpected error in staging. I am investigating the issue and will update the team once I understand the root cause.
>
> If the issue is resolved today, I expect to finish the remaining tasks before the end of the sprint.

## 4. Translation Practice

Translate to Vietnamese:

1. I finished the implementation yesterday.
2. I am currently working on the database migration.
3. I am blocked by an API issue.
4. I am waiting for the frontend team.
5. I expect to finish the task today.
6. Once this is done, I will start the next task.
7. There are no blockers at the moment.
8. I need more information before I can continue.

## 5. Reverse Translation

Dịch sang English:

1. Hôm qua tôi đã hoàn thành phần implementation.
2. Hôm nay tôi đang làm database migration.
3. Hiện tại tôi đang bị block bởi một vấn đề với API.
4. Tôi đang chờ frontend team.
5. Tôi dự kiến hoàn thành task hôm nay.
6. Sau khi hoàn thành việc này, tôi sẽ bắt đầu task tiếp theo.

## 6. Mini Standup

Tự viết 3 câu:

```text
Yesterday:
Today:
Blocker:
```

**80/20:** `I worked on...` / `I am working on...` / `I am blocked by...` / `I am waiting for...` / `I expect to...`
